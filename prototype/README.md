# iStoreOS MCP 权限管理 · 交互原型

直接打开 `index.html`。无需安装依赖，也可使用项目中的本地预览服务器。

所有信息均为模拟。页面没有路由器网络调用、真实认证、真实令牌、持久化授权或配置修改能力；不能作为生产权限控制使用。刷新页面恢复初始数据。

## 建议体验路径
1. 概览 → 审阅 Codex 节点切换申请 → 授权15分钟并执行 → 权限页查看倒计时。
2. 审阅管理地址申请 → 核对风险并批准 → 模拟重新连接 → 确认保留，或立即恢复。
3. 演示控制台 → 添加管理地址申请 → 执行后快进5分钟，观察超时恢复。
4. 停止全部AI操作，确认查询保留、临时权限清空、待执行申请取消。
5. 客户端页新建、配置查询、调整限流、撤销令牌；审计页筛选和导出记录。
6. 演示控制台模拟重启，检查未确认修改恢复、临时授权清除、查询保留。

手机上可通过桌面浏览器响应式模式预览390px布局。本地预览服务器仅监听127.0.0.1，不向局域网公开。

原型为 LuCI 插件拟采用的交互设计；独立地址网页是后续备选。当前root SSH不受MCP权限页约束。
